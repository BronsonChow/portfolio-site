# Commits and versions guide
Basic syntax: x.y.z.a*
| Category | Coverage |
| :--- | :--- |
| x - Release Version | &bull; 0 : Early version <br> &bull; 1 : Release version |
| y - Major Updates | &bull; New pages <br> &bull; Architecture refactor |
| z - Minor updates | &bull; Patching pre-existing pages <br> &bull; Documentation edits |
| a* - Very minor updates | &bull; Minor style changes <br> &bull; Backend optimizations <br> &bull; Bug Fixes |
